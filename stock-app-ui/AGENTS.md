# smallFish UI agent instructions

These instructions apply to all work under `stock-app-ui/`.

- Read `docs/UX_GUIDANCE.md` before creating or changing user-facing UI.
- Treat `src/styles.scss` and `src/app/shared/ui/` as the implementation sources
  of truth for design tokens, shared primitives, drawers, and modals.
- Reuse established patterns before adding component-local variants.
- Preserve data bindings and business behavior during styling-only work.
- Verify affected UX with representative data as well as the Angular build.
- Update `docs/UX_GUIDANCE.md` when intentionally changing an app-wide UX
  convention.

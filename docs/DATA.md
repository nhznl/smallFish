# Data

Everything smallFish stores lives under `SFP_DATA_DIR` (default `<repo>/data`)
and `SFP_LOG_DIR` (default `<repo>/logs`). Both are git-ignored.

**No market data is committed to this repository, and none may be.** Providers
grant you access under their own terms; those terms generally permit personal
and research use but not redistribution. Each user downloads their own data.

## Starter data

```bash
./commands.sh bootstrap-data
```

| | |
|---|---|
| Symbols | Every ETF in `utilities/config/universe.yaml#etf_seed` (97 today) plus `AAPL` and `MSFT` |
| Years | January 1 of **last** year through December 31, and January 1 of **this** year through today |
| Source | Yahoo Finance via `yfinance` |
| Duration | 2–5 minutes, throttled |
| Size | ~2 MB |

Years are derived at run time, so this stays correct across a new year.

The starter universe is intentionally small. `./commands.sh universe` refreshes
the full index universe (several thousand symbols from Wikipedia index pages and
index providers), which is much slower; `./commands.sh scrape` then fills it in.

### Seeded portfolios

On a **first run only**, bootstrap writes five portfolios so the Portfolios view
opens with something to look at:

| Portfolio | Symbols |
|---|---|
| Defensive - Concentrated | XLP, XLU, XLV |
| Defensive - Broad | VDC, VHT, VPU |
| XLY | XLY |
| XLI | XLI |
| XLF | XLF |

They are ordinary portfolios — rename, edit, or delete them freely.

Every symbol is an ETF-seed member, so all of them are priced by the same
bootstrap run. A test enforces that: a portfolio referencing a symbol bootstrap
does not download would render as unpriced rows.

They are written only when `data/portfolios/portfolios.csv` does not exist.
Portfolios are user-authored content, so an empty file means you deleted yours —
rerunning bootstrap will not resurrect them. Skip with `--no-seed-portfolios`,
or set `portfolios.enabled: false` in `starter_data.yaml`.

Each member is priced from the configured `created_date` when that date is
inside the cached range, and from the earliest cached session otherwise — so
these keep pricing correctly however long from now someone bootstraps.

### Configuration

`utilities/config/starter_data.yaml` controls the starter set. The ETF seed is
pulled live from `universe.yaml` rather than duplicated, so the two cannot
drift. `required_for_sectors` asserts that SPY and the eleven sector SPDRs are
present, so an edit to the seed cannot silently break the Sectors route.

### Partial failure

A symbol can legitimately return nothing: delisted, renamed, or listed after the
window began. Those are reported and tolerated. The command exits non-zero only
when:

- a symbol in `always_required` (SPY) produced no data, or
- more than `max_failure_ratio` (20%) of requested symbols produced none —
  which usually means a network or provider problem rather than delistings.

Failures never corrupt successfully fetched data.

### Rerunning

A symbol whose year file already holds data is **skipped, not re-downloaded**.
A second run of a healthy cache therefore finishes in under a second and makes
no network call, reporting how many symbols it passed over.

That split is deliberate: `bootstrap-data` seeds a starter cache, and
`./commands.sh scrape` keeps it current by appending only the missing sessions.
Use `--refresh` to force a re-download of years you already have.

### Flags

| Flag | Effect |
|---|---|
| `--refresh` | Re-download symbols already cached for the target years |
| `--dry-run` | Print the resolved plan, download nothing |
| `--symbols NVDA AMD` | Fetch specific symbols instead of the starter set |
| `--year 2025` | Fetch one year; repeatable |
| `--delay 0.5` | Seconds between provider requests |
| `--threads 5` | Parallel workers |

Rerunning is always safe. It rewrites only the years and symbols requested and
never touches another symbol's cache.

### Price cache format

```
MM-dd-yyyy,open,high,low,close,adjClose,volume
```

One line per session, two-decimal rounding, `adjClose` mirroring `close`
(`auto_adjust=True`, one consistent adjustment vintage). Files are written
atomically.

This format is a contract. Do not introduce a second one, and do not write the
cache without going through the scraper's validation — see
[ARCHITECTURE.md](ARCHITECTURE.md).

## Committed vs generated

Almost everything under `data/` is generated and ignored. The exception:

| Committed | Why |
|---|---|
| `data/studies/catalog.json` | The Research Studies catalog the API serves |
| `data/studies/<id>/study.json` | One materialized study record each |

These are the project's own research output — aggregate statistics only, no
positions, no account identifiers, no provider-licensed raw data. They are
committed so a fresh clone has working Research Studies with no downloads, and
they remain readable regardless of where `SFP_DATA_DIR` points.

The **pinned evidence** those artifacts were built from (backtest summaries,
trade CSVs, study run directories) is *not* committed: it is generated data, and
its metadata embeds absolute developer paths. Rebuilding a study therefore needs
a checkout where the studies were actually run. See
[ARCHITECTURE.md](ARCHITECTURE.md#research-studies).

## Freshness

`./commands.sh doctor` reports the cached year range, symbol count, and whether
the current year is present.

The `/portfolios` response carries `prices_stale` and `last_expected_session`,
and views label stale data. Incremental updates:

```bash
./commands.sh scrape
```

The scraper appends only missing sessions. A dividend or split in the fetched
window triggers a whole-history rewrite for that symbol, so adjustment vintages
stay consistent. A symbol whose fetch stays empty past `stale_after_days`
(default 10) is retired as delisted.

## Rebuilding

| To rebuild | Run |
|---|---|
| One symbol's year | `./commands.sh scrape-history --year 2026 --symbols AAPL` |
| Everything from scratch | delete `data/`, then `./setup.sh` and `./commands.sh bootstrap-data` |
| The universe registry | `./commands.sh universe` |
| Sector snapshot | `./commands.sh sector-rotation` |
| Research Studies JSON | `./commands.sh studies build` (needs the pinned evidence) |
| Validate studies without rebuilding | `./commands.sh studies validate` |

Failed scrapes are recoverable: `./commands.sh scrape-retry` reruns the previous
run's failures.

## Backup

`data/` is fully regenerable from providers except for two things:

- **Symbol Ledger metadata and archive CSVs** — your notes and completed-period
  boundaries. Not recoverable from a provider. Back them up.
- **Portfolio Analysis profile and classification metadata** — your selected
  limits and account-scoped overrides. Not recoverable from a provider. Back
  them up.
- **Long price history.** Regenerable, but a full multi-year backfill is slow
  and rate-limited.

Broker ledgers can be re-synced from the providers.

## Privacy

- Everything is local. smallFish has no telemetry and no service of its own.
- `data/ledger_trading/` and `data/ledger_retirement/` contain your real
  positions, cost basis, and transaction history. Never attach them to an issue,
  a pull request, or a screenshot.
- Redact before sharing diagnostics. `./commands.sh doctor` output is already
  safe: it reports counts and paths, never contents or secrets.

| Yahoo Finance (`yfinance`) | Price history (batch scraper); live company info on `GET /stocks/{symbol}/info` | Unofficial API. Rate-limited, occasionally changes shape. Personal use. Company info is the FastAPI live-fetch exception — see `stock-app/README.md`. |

None of these grant redistribution rights. See

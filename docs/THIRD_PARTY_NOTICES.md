this repository. Each package is installed at its pinned version from its own

## Market data

No market data is committed to this repository, and none may be.

- OHLCV history is downloaded at run time by `./commands.sh bootstrap-data` and
  `./commands.sh scrape` into the git-ignored `data/` directory.
- Providers (Yahoo Finance via `yfinance`, Finnhub, Tastytrade, SnapTrade) grant
  access under their own terms of service. Those terms generally permit personal
  and research use but **do not** grant redistribution rights.
- Each user downloads data under their own use of the provider. Do not commit,
  publish, or redistribute fetched price, earnings, quote, or holdings data.
- Index membership sources (Wikipedia list pages) are used to build the universe
  registry at run time. Wikipedia content is CC BY-SA; only the resulting symbol
  list — factual data, not creative expression — is retained locally, and it is
  not committed.

See [`DATA.md`](DATA.md) for the runtime data directory schema and freshness
rules.

## Committed research artifacts

`data/studies/catalog.json` and `data/studies/*/study.json` are materialized
Research Studies output generated by this project from its own code and pinned
evidence. They contain aggregate statistics only — no personal positions, no
account identifiers, and no provider-licensed raw data. They are authored by the
project and covered by the repository license.
